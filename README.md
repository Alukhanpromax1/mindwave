# MindWave — Imagine. Grow. Repeat.

A cinematic, interactive concept prototype of an EEG-based brain-computer interface (BCI) visual-feedback experience.
Team 7086 · NYAS Junior Academy Innovation Challenge 2026 · BrainTech.

**Conceptual prototype only. Not a validated medical device or clinical treatment.**

- Single self-contained `index.html` (HTML, CSS, JS, inline SVG, canvas). No dependencies, works offline.
- No EEG hardware is connected. All signals, classifier states and game metrics are simulated and labelled as such.
- Deploy with GitHub Pages (serve from the repository root) or open `index.html` directly in a browser.
